# User Stories

## Amaç

Bu doküman, Günlük Giriş Ödül Sistemi kapsamında oyuncuların ihtiyaçlarını kullanıcı bakış açısından tanımlamak amacıyla hazırlanmıştır.

---

# User Stories

| ID    | User Story                                                                                                                                              | Öncelik |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| US-01 | **Oyuncu olarak**, her gün oyuna giriş yaptığımda günlük ödül almak istiyorum, **böylece** düzenli giriş yaparak ödüller kazanabilirim.                 | Yüksek  |
| US-02 | **Oyuncu olarak**, mevcut giriş serimi görüntülemek istiyorum, **böylece** kaç gündür düzenli giriş yaptığımı takip edebilirim.                         | Orta    |
| US-03 | **Oyuncu olarak**, bir sonraki gün hangi ödülü kazanacağımı görmek istiyorum, **böylece** oyuna tekrar giriş yapmak için motive olabilirim.             | Orta    |
| US-04 | **Oyuncu olarak**, kazandığım ödülün envanterime eklendiğini görmek istiyorum, **böylece** ödülümü güvenle kullanabileceğimi bilebilirim.               | Yüksek  |
| US-05 | **Oyuncu olarak**, aynı gün içinde tekrar ödül almaya çalıştığımda bilgilendirilmek istiyorum, **böylece** neden tekrar ödül alamadığımı anlayabilirim. | Yüksek  |
| US-06 | **Oyuncu olarak**, günlük giriş serim bozulduğunda bunun nedenini görebilmek istiyorum, **böylece** tekrar nasıl ilerleyeceğimi anlayabilirim.          | Orta    |
| US-07 | **Oyuncu olarak**, günlük ödül sisteminin herkes için aynı kurallarla çalışmasını istiyorum, **böylece** adil bir oyun deneyimi yaşayabilirim.          | Düşük   |

---

# Öncelik Seviyeleri

| Öncelik | Açıklama                                                                       |
| ------- | ------------------------------------------------------------------------------ |
| Yüksek  | Sistemin çalışabilmesi için kritik öneme sahip kullanıcı ihtiyaçlarıdır.       |
| Orta    | Oyuncu deneyimini geliştiren ancak temel işleyişi etkilemeyen ihtiyaçlardır.   |
| Düşük   | Oyuncu memnuniyetini artıran ve gelecekte değerlendirilebilecek ihtiyaçlardır. |
